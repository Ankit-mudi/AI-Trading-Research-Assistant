# AI Usage Note — TradeLens AI

## 1. How AI Was Used

AI tools were used during the development of this prototype mainly for:

- Understanding and breaking down the assignment requirements
- Planning the ASK → CLARIFY → DEFINE → TEST → LEARN workflow
- Structuring the project into frontend and backend components
- Debugging code and development errors
- Improving the user interface and presentation
- Reviewing the experiment design and identifying possible limitations
- Generating and refining documentation

AI assistance was used as a development aid, while the final project structure, experiment assumptions, and implementation decisions were reviewed and understood before being included.

---

## 2. AI Analyzer in the Prototype

The current prototype does not depend on a live external LLM API.

Instead, the application contains a local deterministic analyzer that identifies important information from the user's trading question, such as:

- Market/instrument
- Sharp-fall threshold
- Holding period
- Historical test period
- Missing information
- Initial hypothesis

This approach was chosen so that the prototype remains functional without requiring an external API or API credits.

The analyzer is therefore an AI-style reasoning component for the prototype, but it should not be described as a live generative AI model.

---

## 3. What AI Did Not Decide

The core research decisions were not blindly delegated to an AI system.

The prototype explicitly defines:

- What qualifies as a signal
- How the return is calculated
- How the holding period is applied
- The simplified transaction-cost assumption
- How evidence is separated from the final conclusion
- Which limitations and follow-up questions should be shown

These decisions are important because the goal of the project is not only to generate an answer, but to make the reasoning behind the answer visible.

---

## 4. Future AI Extension

A future version could replace or extend the local analyzer with a live LLM.

A live LLM could help with:

- Understanding more natural variations of research questions
- Detecting ambiguity more flexibly
- Asking better clarification questions
- Converting natural-language questions into structured experiment parameters
- Suggesting additional experiments

However, the numerical test results would still be generated by the research engine from historical data rather than being invented by the LLM.

---

## 5. Key Principle

AI is used as a reasoning and development assistant, not as a replacement for evidence.

The system follows:

**Question → Clarification → Experiment → Data → Evidence → Learning**

This keeps the research process transparent and makes it possible to distinguish between what the data actually shows and what the system concludes.
